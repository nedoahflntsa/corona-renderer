## Overview

Corona Renderer is an unbiased, physically correct rendering engine for architects and designers, delivering photorealistic results with simple material setup, automatic light sampling, and cloud rendering.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Corona Renderer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Unbiased Rendering** | Physically correct path tracing with automatic light importance sampling |
| **Interactive LightMix** | Adjust individual light intensities and colors after rendering |
| **Chaos Scatter** | Procedural object scatter for vegetation, crowds, and surface detail |
| **Cloud Rendering** | One-click cloud render submission with farm cost estimation |
